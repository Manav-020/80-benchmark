# Fixed experiment protocol

Saved before fitting models. All experiments are exploratory because both datasets have already been examined in previous development. The primary feature count is 50. There is no tuning, optional feature-count analysis, seed search, threshold search, or duration selection using held-out scores.

GSE99511: six leave-one-Sentrix-chip-out folds, plus five-fold stratified CV repeated with seeds 1701, 4201, 202601. GSE46306: strict 20 Normal/17 CIN3 primary cohort; five-fold stratified CV with the same repeat seeds. No independently verified chip IDs are available for this cohort. Unique author/sample IDs provide no evidence of repeated measurements, but absent person IDs mean repeated-person identity cannot be excluded. Random CV does not establish unseen-chip transfer. The reconciled cohort adds GSM1128506 only after supplementary label verification. Original fold assignments remain unchanged; the added participant is assigned to fold 0, 1, 2 in repeats 0, 1, 2 respectively, for every method.

Transfer: GSE99511 to strict and reconciled GSE46306, and strict GSE46306 to GSE99511. Probe-ID intersection is a schema step, not statistical harmonization. No joint normalization; all fitted statistics, feature ranks, diffusion and classifier training use source samples only.

Within each training partition: restrict to cg probe IDs; drop >25% missingness; median impute; remove variance <=1e-8; rank by ANOVA F with ascending probe ID ties; select 50; fit classifier standardization using real training rows. Shrinkage LDA uses lsqr, auto shrinkage, empirical priors, and threshold 0.5. Real-only runs once. Each augmentation runs seeds 17, 42, 2026; final count is twice the largest real training class count per class. SMOTE uses Euclidean neighbors in selected beta space and k=min(5,n_class-1), implemented directly with uniform interpolation; too-small classes fail explicitly.

DDPM: custom continuous, class-conditional noise-predicting MLP; two hidden layers width 128, learned timestep and class embeddings width 16, SiLU, 100 diffusion steps, linear beta schedule 1e-4 to .02. AdamW lr=.001, weight decay=.01, batch <=32, exactly 2000 updates. These are engineering choices, not optimized parameters. CPU with one thread is the predefined default for this small network; CUDA is configurable. Clip beta to [1e-4,1-1e-4], logit, fit real-training mean/scale, train, reverse sample using DDPM posterior variance, invert with stable sigmoid. Invalid generations fail; zero numerical retries; no filtering or resampling. Sampling seed is training seed +100000. Loss is logged every 20 updates and at the last update. Checkpoints include architecture, weights, optimizer, generator statistics and a sidecar with selected CpGs and classifier preprocessing.

Report pooled real held-out balanced accuracy, ordinary accuracy, CIN3 sensitivity, Normal specificity, ROC AUC, confusion counts, timings and failures. Repeated CV pools once per repeat/seed; variation across repeats/seeds is descriptive. Compare each augmentation with its matched real-only repeat. Synthetic rows are not participants. LOCO reports each chip, pooled OOF metrics, and unweighted chip means separately. Single-class chip balanced accuracy is undefined and its recall remains visible. The 80% flag is computed from observed metrics, never a stopping or tuning target.

Diagnostics use real training and generated samples only: per-class means/stds, correlation matrices and mean absolute correlation differences, Euclidean nearest real distances, self-excluded real-to-real reference distances, duplicate counts at exact and maximum-coordinate tolerance 1e-6, boundary fraction <=1e-4 or >=1-1e-4, and invalid counts. Boundary fraction >10% is flagged descriptively without rejection. They do not prove biological validity or privacy.

Outputs resume only when code, config, source hashes and splits fingerprint match. Smoke uses five updates and one seed, is explicitly non-scientific, and is excluded from reports. Failure records remain visible. Aggregate reports are rebuilt from predictions and checked against saved fold metrics.
