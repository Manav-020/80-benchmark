# Data provenance

Sources: [GSE99511](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE99511), [GSE46306](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE46306). Reference implementation inspected locally: [repository](https://github.com/manavdhamecha77/Cervical-Methylation-Feature-Selection). External input files remain read-only. Exact source paths, file sizes and SHA-256 hashes are recorded locally in outputs/audits/sources.json. No dataset redistribution rights or code license are asserted.

GSE99511 inputs are intermediate/beta_values.parquet (probes by Sentrix keys) and metadata/sample_metadata.csv. Labels are cross-checked with metadata/metadata.csv. Four SCC samples are excluded by verified diagnosis, retaining 28 Normal and 36 CIN3. Six chip IDs come from Sentrix metadata, not inferred titles. The reference 02_process_idat.py invokes methylprep with sesame=True, beta export, float32, the 450k manifest. Installed methylprep source describes sesame mode as channel inference, detection masking, quality masking, Noob and nonlinear dye correction. These are code/provenance evidence, not an independently rerun reconstruction or proof of every historical execution flag. Observed missingness is audited. No new IDAT preprocessing is performed.

The reference QC report documents a global >25% missingness filter and removal of non-cg probes (405336 retained). This project deliberately starts from the earlier reconstructed 485512-row matrix and applies cg restriction and fold-local missingness filtering, avoiding reuse of the global QC filter. Existing per-sample reconstruction masks are inherited. No additional SNP, cross-reactive, sex chromosome or detection-P filtering is claimed.

GSE46306 uses the official processed supplementary matrix for individual sample beta values, ignoring its supervised summary statistics and original row ordering for feature ranking. The series matrix supplies accession IDs, author-title mappings and primary diagnoses. Its 44 samples comprise 20 Normal, 17 explicit CIN3, six cancer and one diagnosis-missing sample. The supplementary first header links author 2010041 to g1; the explicit series diagnoses of other g1 samples verify g1=CIN3. This adds GSM1128506 only in the predefined reconciled sensitivity cohort. Supplementary cancer g2 corresponds to series description g3, verified through disease metadata.

Scale evidence is reproduced from actual files: individual processed values are compared to signal-file AVG_Beta for 12 probes across all 44 samples; supplementary CIN3 and Normal means are checked against means of arcsin(sqrt(beta)); the first 1000 readable series table rows are compared with processed values. The local series gzip is truncated, detected by a full stream integrity scan. Its complete metadata header is readable; the damaged series table is not a modeling input. Supplementary processed and signal streams were read through their ends without gzip errors. Machine-readable evidence is saved under outputs/audits and small scale-check tables are copied into reports after audit. This supports using deposited sample values directly as beta. The contradictory GEO VALUE description remains a limitation. No transformation is chosen using accuracy.

cg00979000 is absent from the processed matrix and is checked in the signal matrix, including the missing AVG_Beta for author 2010040/GSM1128505. It is not restored, and its exclusion mechanism is not assumed. Transfer restricts to shared processed/reconstructed CpG IDs.

No independently verified GSE46306 chip or repeated-person mapping was found. Array-position-like title prefixes alone are insufficient to establish chip identities. Unique author IDs do not establish that distinct IDs are different people; absent person identifiers are a limitation.
